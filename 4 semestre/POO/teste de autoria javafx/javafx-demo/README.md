# JavaFX Demo

Projeto JavaFX simples criado automaticamente.

Como executar:

- Usando o plugin JavaFX do Maven:
  mvn javafx:run

- Compilar e executar com Maven:
  mvn package
  java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -jar target/javafx-demo-1.0-SNAPSHOT.jar

Substitua /path/to/javafx-sdk/lib pelo caminho do SDK JavaFX no seu sistema se necessário.
